用原生 JS 实现暗色模式、目录与代码复制

2026-09-10 · JavaScript 前端

这个站没有引入任何框架。这篇文章拆开 assets/main.js， 看看那些通常由博客主题提供的功能，用原生 API 实现起来到底要多少代码。

设计原则：全部渐进增强

每一段脚本都遵守同一条规则：先判断目标元素在不在，不在就安静返回。 因此：

  • 首页不会去执行「生成目录」；
  • 文章页不会去执行「站内搜索」；
  • 禁用 JavaScript 后，正文、样式、链接全部照常工作，只是少了几个按钮。
var btn = document.querySelector('#themeToggle');
if (!btn) return;      // ← 这个模式重复出现在每个 init 函数开头

暗色模式：关键在「不闪烁」

最容易踩的坑是：等 DOMContentLoaded 再读 localStorage 设置主题， 用户会先看到一帧白屏再跳到深色。解法是把这段脚本同步塞在 <head> 里， 并且放在样式表之前： 

<script>
  (function () {
    try {
      var saved = localStorage.getItem('theme');
      var dark = saved ? saved === 'dark'
                       : matchMedia('(prefers-color-scheme: dark)').matches;
      document.documentElement.dataset.theme = dark ? 'dark' : 'light';
    } catch (e) {}
  })();
</script>

它只做一件事：在浏览器开始绘制之前，把 data-theme 写到 <html> 上。样式侧只需要两组 CSS 变量： 

:root                { --bg: #f5f6f8; --text: #191c20; }
[data-theme="dark"]  { --bg: #0e1114; --text: #e8ebef; }

真正切换主题的函数在 main.js 里，只有几行——写属性、存 localStorage、换图标： 

btn.addEventListener('click', function () {
  var next = document.documentElement.dataset.theme === 'dark' ? 'light' : 'dark';
  document.documentElement.dataset.theme = next;
  localStorage.setItem('theme', next);
});

顺手加一行 color-scheme: light / dark， 浏览器的滚动条、表单控件、默认背景就会跟着一起变色，不用自己写。

目录：从正文里长出来

不用手写目录，也不用额外配置——直接扫正文里的 h2 和 h3。 中文标题没有合法的 id，所以要自己生成一个，并且处理重名： 

var heads = document.querySelectorAll('.prose h2, .prose h3');
var used = {};

heads.forEach(function (h, i) {
  if (h.id) return;
  var base = h.textContent.trim().toLowerCase()
    .replace(/[^\w\u4e00-\u9fa5]+/g, '-')     // 中文要显式保留
    .replace(/^-+|-+$/g, '') || ('section-' + i);

  var id = base, n = 2;
  while (used[id] || document.getElementById(id)) id = base + '-' + (n++);
  h.id = id;
  used[id] = 1;
});

列表少于两项时直接把目录整个删掉，避免出现只有一个条目的尴尬侧栏： 

if (heads.length < 2) { toc.remove(); return; }

滚动高亮

IntersectionObserver 也能做，但在「最后一项永远点不亮」这类边界上比较烦。 这里用一个更朴素也更可靠的办法：找出最后一个顶边已经越过分隔线的标题。 

function highlight() {
  var current = links[0];

  for (var i = 0; i < heads.length; i++) {
    if (heads[i].getBoundingClientRect().top <= 100) current = links[i];
    else break;                 // 标题按文档顺序排列，可以提前退出
  }

  // 滚到底部时强制点亮最后一项
  if (window.innerHeight + window.scrollY >= document.body.offsetHeight - 4) {
    current = links[links.length - 1];
  }

  links.forEach(function (a) { a.classList.toggle('active', a === current); });
}

配合 requestAnimationFrame 节流，滚动时不会每个事件都触发一次重排： 

var ticking = false;
window.addEventListener('scroll', function () {
  if (ticking) return;
  ticking = true;
  requestAnimationFrame(function () { highlight(); ticking = false; });
}, { passive: true });

代码复制：运行时注入按钮

与其在每个 <pre> 里手写一个按钮，不如让脚本自己加。 这样正文保持干净，复制粘贴别人的代码片段也不用改结构： 

document.querySelectorAll('.prose pre').forEach(function (pre) {
  var btn = document.createElement('button');
  btn.className = 'copy-btn';
  btn.textContent = '复制';

  btn.addEventListener('click', function () {
    var code = pre.querySelector('code') || pre;
    navigator.clipboard.writeText(code.innerText).then(function () {
      btn.textContent = '已复制';
      setTimeout(function () { btn.textContent = '复制'; }, 1600);
    });
  });

  pre.appendChild(btn);
});

按钮默认 opacity: 0，靠 pre:hover .copy-btn 显示。 触屏设备没有 hover，所以在窄屏媒体查询里把它强制设为可见。

站内搜索：两级降级

搜索走 search-index.json（由 tools/build.mjs 从文章里提取生成）， 支持全文匹配。但如果这个文件不存在——比如你还没跑过构建脚本——它会自动降级为 「只匹配页面上已经渲染出来的卡片文字」，功能弱一些但不会报错： 

fetch(new URL('search-index.json', ROOT))
  .then(function (r) { return r.ok ? r.json() : null; })
  .then(function (data) { index = Array.isArray(data) ? data : null; })
  .catch(function () { /* 静默降级到 DOM 过滤 */ });

其中 ROOT 是从 <script src> 反推出来的站点根路径， 所以同一份 main.js 在 / 和 /posts/ 下都能正确工作， 甚至直接用 file:// 打开也能跑： 

var SELF = document.currentScript && document.currentScript.src;
var ROOT = SELF ? new URL('../', SELF) : new URL('./', location.href);
